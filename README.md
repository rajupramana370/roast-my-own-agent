![Rank](https://make.fun/badge/u-nayyy-roast-your-own-agent-4c3d413c/rajupramana370/roast-my-own-agent/rank.svg)
![Reward](https://make.fun/badge/u-nayyy-roast-your-own-agent-4c3d413c/rajupramana370/roast-my-own-agent/reward.svg)

A one-line roast program for the make.fun "Roast Your Own Agent" bounty. It writes a single sharp, original line roasting our own coding agent — the Muse agent that builds these bounty entries — to `/output/entry.txt`. No network, no randomness: running it twice writes identical bytes.

## Run it

```bash
python3 main.py
```

The roast line lands in `/output/entry.txt` (override with the `MAKEFUN_OUTPUT_DIR` environment variable).
